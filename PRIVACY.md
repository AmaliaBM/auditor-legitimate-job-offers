# Privacy Policy / Política de Privacidad - LinkedIn Job Fraud Auditor

## English
This extension does not store, harvest, or monetize any user data. 
- **Data processed:** The extension only reads the text content of the job posting currently opened by the user when the "Analizar Oferta Actual" button is pressed.
- **Data transmission:** This text content is securely sent to our self-hosted API on Render strictly to calculate the security risk score using open-source heuristic algorithms and public OSINT data (PhishTank/RDAP).
- **Data retention:** No personal data, IP addresses, or browsing history are logged, saved, or persisted on our servers. All analysis occurs volatilely in-memory.

## Español
Esta extensión no almacena, recolecta ni monetiza ningún dato del usuario.
- **Datos procesados:** La extensión solo lee el contenido de texto de la oferta de empleo abierta actualmente por el usuario cuando se presiona el botón "Analizar Oferta Actual".
- **Transmisión de datos:** Este contenido de texto se envía de forma segura a nuestra API alojada en Render estrictamente para calcular el puntaje de riesgo de seguridad utilizando algoritmos heurísticos de código abierto y datos públicos de OSINT (PhishTank/RDAP).
- **Retención de datos:** No se registran, guardan ni persisten datos personales, direcciones IP ni historiales de navegación en nuestros servidores. Todo el análisis ocurre de forma volátil en memoria.
